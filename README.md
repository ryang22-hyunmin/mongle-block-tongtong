# 몽글몽글 블록 통통 🍡

귀여운 블록 친구들과 함께하는 파스텔 테트리스 게임입니다.
HTML 파일 하나로 동작하며, 별도 설치나 빌드가 필요 없습니다.

## 플레이
- 온라인: GitHub Pages 주소 (`https://<아이디>.github.io/<저장소명>/`)
- 로컬: `index.html`을 브라우저에서 열기

## 조작
| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↑ / X | 회전 (Z: 반대 방향) |
| ↓ | 살살 내리기 |
| Space | 쿵! 내리기 |
| C | 홀드 |
| P | 일시정지 |

모바일에서는 화면 아래 터치 버튼으로 조작합니다.

## 특징
- 일곱 가지 블록 친구 (구름이·병아리·포도젤리·완두콩·복숭아·블루베리·귤이)
- 줄이 사라질 때 울리는 효과음, 콤보가 이어질수록 음이 올라감
- 연속 콤보·연속 테트리스 보너스
- 레벨 3마다 새로운 단계 (보드 배경이 바뀜)
- 최고 점수 브라우저 저장
